## About

This repository is my SQL practice space, built on Microsoft's **AdventureWorks2025** sample database.
I solve business-style questions, write the theory in my own words, and track my progress day by day.

The aim is to think like a **data scientist**: ask a business question, write the query, and understand why it works.

## What is inside

| Folder | What it contains | Status |
|--------|------------------|:------:|
| [30_Days_Challenge](30_Days_Challenge/) | 5 queries a day for 30 days, with theory notes | ⏳ In progress |
| Business_Questions | Bigger real-world questions using joins, CTEs and window functions | 🔒 Planned |
| Notes | Cheat sheets and theory summaries | 🔒 Planned |

## Topics covered

`Data Retrieval` · `Data Cleaning` · `Aggregations` · `Joins` · `Subqueries` · `CTEs` · `Window Functions` · `PIVOT` · `JSON` · `Temp Tables` · `Indexes` · `Views` · `Stored Procedures` · `Python Connectivity`

## How to run

1. Install **SQL Server** and **SSMS**.
2. Download `AdventureWorks2025.bak` from [Microsoft's sample databases](https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure).
3. In SSMS, right-click **Databases**, choose **Restore Database**, and select the `.bak` file.
4. Open any `.sql` file from this repository and run it.
